Acessibilidade

O projeto foi desenvolvido considerando boas práticas de acessibilidade.

Recursos utilizados
Uso de elementos semânticos como header, nav, main, section e footer.
Uso de label associado aos campos do formulário.
Uso de aria-label no botão do menu.
Navegação por teclado nos elementos interativos.
Indicação visual de foco nos botões.
Cores e contrastes definidos para facilitar a leitura.
Estrutura organizada para facilitar a navegação por leitores de tela.

Essas medidas foram aplicadas para tornar o site mais acessível e facilitar a utilização por diferentes usuários.
